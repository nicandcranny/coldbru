# Security

ColdBru handles API requests, local files, environments, and developer secrets, so security matters.

If you believe you have found a security issue, please report it privately through [GitHub Security Advisories](https://github.com/nicandcranny/coldbru/security).

## Reporting a Vulnerability

When reporting a vulnerability, please include as much detail as you can:

- Type of issue
- Affected file paths or code locations
- Affected version, branch, tag, or commit
- Any special configuration needed to reproduce it
- Step-by-step reproduction instructions
- Proof of concept or exploit code, if available
- Potential impact

Examples of relevant issues include:

- token or secret exposure
- unsafe file access
- request execution vulnerabilities
- dependency or supply-chain concerns
- privilege escalation or remote code execution

Please do not report security vulnerabilities through public GitHub issues.
